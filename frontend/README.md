# Shared Access frontend

Отдельный интерфейс на JavaScript и Vite: проекты, карточки проектов, документы
точных ревизий, задачи, наблюдаемые изменения и график отчётов по дням UTC.

```powershell
cd frontend
npm install
npm run dev
```

Откройте http://127.0.0.1:5173. Vite проксирует `/api` на
http://127.0.0.1:8000. Другой сервер: задайте `SHARED_ACCESS_API_URL` перед запуском.
В «Подключение» введите персональный bearer-токен. Токен живёт только в памяти
вкладки; после перезагрузки введите его снова. Для API с `--no-auth` токен не нужен.

```powershell
npm test
npm run build
```

Для размещения отдавайте `dist/` через reverse proxy и направьте `/api` на backend
на том же origin. `npm run preview` служит только для локального просмотра сборки;
API для него должен проксироваться отдельно.

Список по умолчанию содержит зарегистрированные задачи и явно помеченные кеши.
Кнопка получения из трекера загружает все страницы живого списка без записи в БД.
Кнопка «Добавить задачу» открывает форму названия, описания и приоритета. После
создания задача сохраняется в трекере и БД, затем открывается её локальная карточка.
Требуется writer/admin с доступом к проекту. При неопределённой ошибке соединения
проверьте живой список перед повторным созданием, чтобы избежать дублей.
У незарегистрированных задач ещё нет локальной истории. Регистрация и синхронизация
выполняются существующими REST/MCP методами с writer/admin доступом.
График строится по загруженным отчётам, следующие страницы загружаются кнопкой.
Изменения — последние 20 наблюдаемых событий API, а не полный аудит трекера.
Отчёт, его Git-связи и проверки отображаются как непроверенные сведения агента.
HTML из описаний и документов не исполняется.
